MEASURED on `masterpieces/Classic Text Adventure Masterpieces of Infocom (USA).bin` (MODE1/2352, 150,515 sectors). **33 distinct builds under `PC/`**, 216 files. Re-derive through the real reader; these came from a hand-rolled ISO9660 walk.

Releases that are NOT held anywhere else in the corpus:

```
Planetfall        v3 r37  s851003  02D6   (Apple retail disk is r29/840118; Mac is v5 r10/880531)
Leather Goddesses v3 r59  s860730  D070   (Mac is v5 r4/880405)
Seastalker        v3 r16  s850603  5890   (Mac is r15/840522)
Ballyhoo          v3 r97  s851218  78AE
Hollywood Hijinx  v3 r37  s861215  F507
```

And confirmations worth having: Trinity v4 r12/s860926 checksum `16AB` is **byte-for-byte the build on the user's C64 disk** (SQ-0869), and the three v6 games match our bare story files exactly — Arthur r74/890714, Journey r83/890706, Zork Zero r393/890714.

THE ARTWORK IS THE PRIZE. Each v6 game sits beside its own PC archives in the same directory — `PC/ARTHUR/` holds `ARTHUR.ZIP` with `ARTHUR.CG1`, `.EG1`, `.EG2`, `.MG1`. That is exactly the pairing SQ-0862 taught `assets::volumes` to resolve, so the existing art discovery should work once the medium mounts, and `.EG1`+`.EG2` is a split set the multi-part walk already knows.

LAYOUT TRAPS, all measured:
- Storage is inconsistent. Some games are `PC/<GAME>/<GAME>.DAT`, others `PC/DATA/<GAME>.DAT`, and Ballyhoo is `PC/BALLYHOO/DATA/BALLYHOO.DAT`. Do not assume one rule.
- **`PC/BALLYHOO/SAVE/BALLYHOO.DAT` is 12,282 bytes and is a SAVED GAME, not a story** — the exact case `looks_like_story` exists to reject, and a good end-to-end check that it still does. There are more `SAVE/` directories.
- The v6 stories are named `.ZIP` — Infocom's own container, nothing to do with PKZIP. An extension-keyed reader would mishandle them, which is another instance of `medium.rs`'s content-not-extension rule.
- ISO9660 names carry the `;1` version suffix; strip it for display or every row reads `ZORK1.DAT;1`.

SCOPE AND SEQUENCING. **SQ-0870 is the prerequisite** — it adds the raw-2352 sector unwrap and the Apple Partition Map walk that gets you to a filesystem at all. Detection of the disc itself is settled there (sync `00 ff×10 00`, mode byte 1, size divisible by 2352, `ER` at logical sector 0). This quest adds the ISO9660 directory walk on top and a `FORMATS` row, which serialises behind SQ-0868 and SQ-0869 on `medium.rs`.

Do NOT copy the 354 MB `.bin` into `stories/` — several suites sweep every file there and would read it on every gate run. Point tests at `masterpieces/` and skip cleanly when absent; CI has neither directory.
