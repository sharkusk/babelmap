## The shape of the fix

`Capture` exposes both `pub bytes: Vec<u8>` (the WIRE stream, which `Flush` offsets index and every bandwidth reading must come from) and `terminal_bytes() -> Cow<[u8]>` (inflated, what a terminal actually interprets). `oracle::resolve` takes `&[u8]`, so either satisfies it and only one is correct.

The field's own doc comment already warns about this — *"Since SQ-0976 that is not the same thing as the stream a terminal interprets: see `Capture::terminal_bytes`"* — and it did not help, because a comment cannot stop a call. `examples/gallery.rs` passed `&c.bytes` and lost every artwork in the project's proof sheet for a day.

**Make the wrong call impossible rather than discouraged.** A newtype that only `terminal_bytes()` can produce, taken by `resolve` (and by `raster::render*`, and anything else that interprets rather than measures), turns this into a compile error. The wire stream stays reachable for the things that genuinely want it — byte counts, `Flush` offsets, the compression measurements SQ-0991 exists to make — but it stops being interchangeable with the decoded stream at the type level.

Note the two uses are genuinely different and both legitimate, which is exactly why naming alone will not fix it: SQ-0991 deliberately kept `Capture::bytes` as the wire *because the wire size is the measurement*. So this is not "one of these is wrong", it is "these are two different things that happen to share a type".

## Why nothing caught it

- **The gate does not run the gallery.** A total loss of artwork was invisible to 5,945 passing tests. One shot asserting non-zero art cells would have caught it the day compression landed. That smoke is worth adding whatever shape the type fix takes.
- **A placement that resolves with no pixels looks like the game drew nothing** — the failure is indistinguishable from a legitimately blank screen, so the art guard reported "the frame puts art on 0 cell(s)" and implicated the story rather than the harness.
- The migration that introduced the split (SQ-0991) updated three call sites and explicitly left `gallery.rs` to avoid a concurrent lane. Correct about ownership, and it still left a consumer of a changed contract behind.

## Also worth doing while here

A failed gallery shot leaves its previous PNG in place, so `index.html` presents stale frames beside fresh ones with nothing marking which is which. That is what made a total regression look partial and cost a round of misdiagnosis.
