## Why scott-cli first

244 lines, exactly one TTY gate, no alternate screen, no cursor control, no status
window to linearise — everything a Scott game says is already prose ("I'm in a forest /
Obvious exits: North. South. East. West."). It is nearly a screen-reader client as
shipped.

The only real change is input: it enables raw mode purely to control echo
(crates/scott-cli/src/main.rs, `enable_raw_mode` with a manual echo loop). Plain mode
should take the cooked branch it already has for non-TTY stdin, which restores the
terminal's own echo and line editing.

It also has NO terminal teardown at all (no OSC/cursor reset — it sets neither, so
nothing leaks today, but that changes the moment it does). Folding it onto the shared
teardown guard from [[SQ-0605]] closes that.

## Value

A day's work for something a real user can actually try, and what it teaches about the
prompt, echo and pacing should shape [[SQ-0606]] for the other two before their much
larger surfaces are touched.
