REGRESSION — reopened. The band beside the drop cap and room icon IS fixed (user confirmed by
eye), but the same build introduced a new artifact.

SYMPTOM: a very thin dark line down both edges of the story pane, on Amiga Zork Zero.
The user attributes it to this fix specifically ("that was introduced with the dropcap fix").

MEASURED off their screenshot (583x850):
  - exactly ONE PIXEL wide, at x=86 (left edge) and x=497 (right edge)
  - colour RGB(130,130,130) against the page's RGB(163,163,163)

The width is the puzzle worth starting from: a cell-level background run cannot produce a
one-pixel line — only a bitmap can, or a rasterised path where runs become pixels rather than
cells. `margin_ground_run` inserts a background run over the reserved columns, which is cells.
So either the artifact is downstream of the runs in a path that rasterises them (the raster
composite, or the hybrid ring's own bands), or the line is not what it appears to be.

I first attributed this to SQ-0824's Triangle downscale blending a hard crop boundary — the
user corrected me. Do not spend time on that theory; bisect instead.
