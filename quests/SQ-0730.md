Follow-up from SQ-0724. The v6 Mysterious Adventures ports now map, and each room is labelled with the exact line the game paints, which begins 'I'm in a ' / 'I'm by a ' / 'I'm on a ' on almost every room — so every node on the map carries the same four-word prefix. The native scott engine labels the same games' rooms with the bare description ('dense SPOOKY Forest'), because ScottFree composes the 'I'm in a ' prefix at print time, so the two engines label the same title differently. Stripping is tempting but not obviously safe: mysterious07's opening room is 'I feel a surge of strange Power', and mysterious02/03/06/08 have rooms whose entire description is 'I'm in a ' or 'I'm in a 0'. Decide whether to strip; if so, keep the corroboration match in zvm::location::object_text_property against the FULL property string — the label is cosmetic, room identity comes from the object number.
