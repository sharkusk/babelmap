--- note 2026-08-12T06:15:12Z ---

USER 2026-08-11: "we should also add a launch arg to specify the graphics side car file".

**Most of this already exists — SQ-0734 landed the resolution.** `PictureOverride::resolve(story_path, game_dir)` reads the `pictures` key from the per-game sidecar, parses the named file, and `PictSource::resolve_with_override` makes a loaded archive beat both an `.adf`'s own `Pic.data` and a Blorb. A named-but-unusable archive is already loud (an `eprintln!` before the alternate screen so it survives in scrollback, plus a `TranscriptKind::Warning` naming the file, the reason, and what was used instead). The archive's flavour already selects the interpreter number unless one is set explicitly.

So this quest is **a second entry point into an existing mechanism**, not new machinery. It should be small.

WHY IT IS WORTH HAVING ANYWAY: the config key requires editing a file *before* you can see the result, which is precisely backwards for a choice you can only judge by looking at it. A CLI arg is the try-it-once path — `babelmap zork0.z6 --pictures stories/zork0.mg1` — and it composes with the shell, so a user can flip between renditions in successive launches without touching any config.

PRECEDENCE, to be decided deliberately rather than by accident: the CLI arg should outrank the per-game config key, matching how an explicit interpreter number already outranks the inferred one, and matching the general rule that the more specific and more recent instruction wins. **Say so in the help text**, because a user with a config key set who passes the flag needs to know which one they are getting.

WORTH DECIDING, not obvious: whether the flag should also accept a bare rendition hint rather than a path — `--pictures mg1` meaning "the MCGA archive beside this story". That is stem-based discovery, which SQ-0734 explicitly rejected **for automatic pairing**; as an explicit user instruction it is a different act, the same way SQ-0789's listing is safe because a human chooses. Attractive, but it is a second feature; ship the path form first.

RELATED: **SQ-0789** (launch options dialog / info panel listing) is the third entry point and the richest one — it can show what is available before you choose. This quest is deliberately the cheap one and should not wait for it.

CAVEAT TO CARRY INTO THE HELP TEXT: per **SQ-0790**, EGA and CGA archives store 640-wide art with half-width pixels and do not yet render at their true aspect. `pictures = "zork0.mg1"` (MCGA) is the DOS rendition that works correctly today. A flag that invites users to try `.eg1` should not leave them puzzled by the result.
