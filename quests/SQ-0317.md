--- note 2026-07-14T06:22:32Z ---

Punch list (each item = a known, documented, honestly-gestalt'd gap from the SQ-0308 wave; details in the w5-task1/2/3 reports + reviews):
1. Line-input echo → echo streams (spec §4.1): completed player input must also write to the window's echo stream; today the typed line is host-drawn and never enters gvm's put path, so SCRIPT-ON-style transcripts miss the >commands. Needs a host→gvm hook at line-input completion (supply_line already crosses the boundary — forward to the window's echo stream there).
2. Unicode normalization: glk_buffer_canon_decompose_uni (0x0123) / canon_normalize_uni (0x0124); gestalt_UnicodeNorm(16) currently 0. Zero-dep constraint means checked-in generated tables (size-bounded subset is not compliant — needs full NFD/NFC).
3. Real local time: the date/time _local selectors currently alias UTC (documented). Zero-dep + no-unsafe means either platform-conditional std extensions or reading TZ env/zoneinfo ourselves — investigate options.
4. Gradual volume ramps: set_volume_ext jumps immediately with correct notify timing; spec intends a gradual change over duration_ms. Needs audio-crate ramp support (rodio has no native ramp — per-tick stepped gain from the host clock).
5. style_distinguish depth: currently colour-hint-only (honest but shallow); could consult recorded weight/oblique/justification hints plus backend rendered differences.
Related, tracked separately: SQ-0316 (pause on empty channel must hold back the next sound).
