## Does SQ-0956's "CGA has different machine colours than EGA" force multiple table rows per machine?

The user asked this directly. **The evidence says no, and the reason is worth writing down here, because "one row per machine" is exactly the assumption this doc encodes.**

`MachineProfile` is keyed by §8.3.3 interpreter NUMBER — 2 Apple IIe, 3 Macintosh, 4 Amiga, 5 Atari ST, 6 IBM PC. A video card is not an interpreter number: an IBM PC with a CGA card and one with EGA are both interpreter 6. So a second row could not be keyed anyway.

More importantly, **the card does not appear to change the PERIOD LOOK at all.** `machine-screenshots/dos-hitchhiker.png` is explicitly "DOS with a CGA colour display", it is Version 3, and its page is `#0F009E` — the interpreter's blue, 92.4% of the frame, the same blue the EGA v6 captures show. So in TEXT mode a CGA machine and an EGA machine look the same, which is what you would expect: CGA text mode can select any of sixteen background colours, and blue is one of them.

What differs is the **v6 GRAPHICS screen**. `machine-screenshots/dos-zorkzero-cga.png` is black because a two-colour graphics mode has no blue to offer. So the axis is not really card-versus-card, it is TEXT MODE versus TWO-COLOUR GRAPHICS MODE — and the thing that tells us we are in the latter is the loaded archive, which lanthorn already parses (`InfocomPics::hardware_palette`).

## What follows for this quest

  - `period_look` keeps ONE row per machine. It is a v1–v4 concept (`crate::period::resolve` gates it), and a v1–v4 story never loads a `.CG1` v6 archive, so the two never meet.
  - `default_colours` gains a per-archive override rather than a row — which is what SQ-0956 implements via `two_colour_colours()`, keyed off the archive rather than off a new machine identity.

So this stays a DOC fix. But it should now also say the card caveat out loud, because the obvious reading of a single "IBM PC" row is that interpreter 6 has one pair, and after SQ-0956 it will have two — blue 6 under white 9 for EGA/MCGA, black 2 under light-grey 9 for CGA. A reader who does not know that will eventually add the row this note says not to add.

Original scope, unchanged: the table still says "Five machines" and omits the IBM PC and Atari ST rows, stale since SQ-0928 and SQ-0933. The SQ-0947 lane fixed only the one bullet its own new paragraph contradicted ("Never for v5 and up", stale since SQ-0935) rather than half-updating the section.

**Do this AFTER SQ-0956 lands**, so the caveat can be written against what actually shipped rather than against a design.
