## Shipped 2026-08-03 — commit e6abedb5

`[Score 1, up 1]` above the prompt, screen-reader mode only, on change only.

### The interesting part: there is no shared score concept
Two of four sources are exact, two are pattern-matching. Recorded because a
future reader will assume this is uniform and it is not:

| format | source | exact? |
|---|---|---|
| Z-machine v1–v3 | global 2 (ZMSD §8.2 reserves it) | yes |
| Z-machine v4+ | the status line the game drew | **no — text** |
| Glulx | the Glk grid text; Glk has NO score concept | **no — text** |
| Scott | treasures in the treasure room, recounted | yes |

A v3 *time* game (Flags 1 bit 1) has a clock where the score would be and must
never be announced — covered by a test.

`score_in_status` takes the LAST `Score: N` on the line so a room called "Score
Board" does not become the score, and returns None (silence) rather than
guessing. Games wording it differently ("Points", a bare number, translated) are
simply not matched. That is a known, deliberate limitation.

### Design choices
- First observation is silent — the starting score is not an event.
- `None` ≠ zero: a menu hiding the status must not read as losing all points,
  and must not discard the last known value.
- Words, not `+1`: readers announce "plus" only at higher punctuation settings.
- Suppressed under `--story-only` (zvm/gvm) — that flag means story text only.

### VM change
`scott::Vm::treasures_stored() -> (i32, i32)`, additive and zero-dep; it is what
`print_score` already computed, now callable. Scott stores no score anywhere.

### Verification, and how I got it
Real games would not cooperate — scoring in Ballyhoo/Enchanter/Infidel/Lost Pig
is puzzle-gated and none moved off 0 in a scripted walk. Used the
redistributable `scott/tests/tiny_cave.dat` and the existing golden win script
instead, where `drop idol` moves the score: announced exactly once, absent
without the flag. The Z-machine per-version source is pinned by a unit test that
writes the global directly (read via `mem.global_vars()` — a hard-coded base
lands in read-only memory and panics).

Also: no spurious announcements across 4 real stories on 3 engines; default-mode
output identical to the previous build across 11 stories; gate 0 errors,
64 == 64; clippy clean; falsified 3 ways.

The opening-score test originally started at 0 and did NOT fail under
falsification — a zero start cannot distinguish "no previous value" from a real
one. Rewritten to start at 10.
