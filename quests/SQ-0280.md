--- note 2026-07-12T03:22:41Z ---

Merged to main (65cbf0a gvm-cli, c28128d zvm-cli, c04aea7 gvm-cli hot-loop fix). Set to confirm — the OSC 11 terminal effect + exit-resets can't be exercised headlessly (pure helpers ARE unit-tested). Manual smoke: (1) a game with a TRUE/24-bit or grey background fills the whole terminal window (margins + below text), both CLIs; (2) --no-game-colours = no page paint; (3) quit / Ctrl-C / Ctrl-D / fault all restore your terminal's own background (no stuck recolour); (4) piped input emits no OSC into captured output; (5) mid-play bg change repaints at the next turn. KNOWN LIMITATION (by design, not a bug): Z-machine STANDARD colours (indices 2..=9: black/red/green/…) are NOT painted as a page background — they're palette-relative everywhere in the codebase (app maps them to scheme.palette[n-2]) and there is no fixed RGB for them; forcing one into OSC 11 would clash with the terminal's own ANSI palette used for text backgrounds. So only true/24-bit/grey backgrounds get the page paint; standard-colour games behave exactly as before (text bg via ANSI SGR, page unpainted). If painting standard colours is later wanted, it needs a deliberate fixed palette choice (new decision).

--- note 2026-07-12T03:30:37Z ---

Accepted tradeoff (user decision, smoke 2026-07-11): with OSC 11 page background, when a game (e.g. Counterfeit Monkey) flips its Normal background mid-session, the terminal repaints ALL default-bg cells — including scrollback — to the new colour, while already-emitted explicitly-coloured runs (CM's white word backgrounds) keep their old colour. Result: prior black-on-white paragraphs go ragged (white word-blocks with new-colour gaps in the inter-word spaces). This is inherent to a scrolling terminal (history can't be retroactively recoloured consistently). Considered fixing by emitting OSC 11 only once (first page colour, never re-emit mid-session); user chose to LEAVE current behavior — the ragged scrollback is acceptable. Do NOT "fix" this later without a new explicit request.
