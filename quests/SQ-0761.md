USER 2026-08-10: "is there a way to dump terminal windows (with formatting but not graphics)?"

There is not. The registry has `export-transcript` (transcript text), `export-svg`/`export-dot`/`export-map` (the map) and `dump-windows` (geometry). Nothing dumps the rendered CELL BUFFER.

WHY IT MATTERS, from this session's evidence: selecting the pane is useless because kitty unicode placeholders come with it (the user's first dump attempt was unreadable). And every Journey defect chased today was ultimately **a colour landing in a cell**, which no geometry dump can show:
- the panel fill painting rows 53..61 under the menu — invisible in `/dump-windows`, obvious in a screenshot;
- the border cells carrying the panel fill's colour instead of the frame's;
- `The Party` absent because the fill covered it, while the cell buffer held the label intact.

Each cost a round trip through a screenshot. A cell dump would have shown all three in one line.

WHAT IT MUST CONTAIN — the styling is the point, not a nicety:
- the glyph grid, so labels and borders are readable as text;
- per-cell foreground/background and attributes, in a form that survives copy-paste as plain text (no ANSI escapes — those paste as unreadable soup and defeat the purpose);
- graphics EXCLUDED, but their placement noted, so a region covered by an uploaded image is identifiable rather than silently blank.

A compact encoding beats a faithful one: a glyph grid plus a legend of distinct styles with the cell ranges each covers reads far better at 115x61 than a per-cell table, and makes "these nine rows all carry the panel fill's background" a single legend line.

DELIVERY: follow SQ-0756's pattern — append to a file under `~/.babelmap/` and name the path in the transcript, since the whole point is that the screen itself is not copyable. Follow SQ-0759's lesson too: it must be reachable from a key binding without opening a modal, or capturing it perturbs the frame being captured.

Registry: one command in `slash::COMMANDS`, verb-noun, per [[command-registry]]. Keys bind to command strings; there is no Command enum.
