context: 'In-game graphics: `glk_image_draw`/`glk_image_draw_scaled` always return success (1) when graphics is enabled, even if the resnum is missing/undecodable — `graphics_draw_image` no-ops but can''t report back (crates/gvm/src/exec.rs 0x00E1/0x00E2 + the `GlkBackend` method). Per the Glk spec the return indicates whether the image drew; a game probing it to detect a missing image is misled (most games ignore it). Fix: give `graphics_draw_image` a `bool` return and thread it to the store. Also: `AppGlk::graphics_draw_image` clones the full decoded `DynamicImage` on every draw (PictSource already caches the decode) — matters for games that redraw the same Pict repeatedly/animated; consider passing a reference or per-canvas caching.
