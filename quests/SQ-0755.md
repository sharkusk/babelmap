If the overwrite only occurs when the story text has somewhere wrong to go, a harness that drove past the intro or rendered the menu frame in isolation would never reproduce it. TEST IT FIRST, before treating these as two investigations: find where the prose is anchored on this frame and check whether the cells it occupies include the header row.
