Decision (2026-07-16): KEPT as a deliberate step toward the standing goal "only the interpreter on the main thread, all else in the background." Important finding: the "delay" that motivated this was mostly a DEBUG-build artifact — the user confirmed the RELEASE build is a lot faster (the O(map) map draw + routing are far slower unoptimized). On explored-room moves nothing re-routes (SQ-0378 memo hit), so the step overlay never appeared and the felt delay was the unoptimized draw, not map computation. We keep the async worker anyway because off-thread map rendering is required by the target architecture and the ~one-frame lag is inherent to it. Full vision (future) moves graph OWNERSHIP to a persistent worker fed by interpreter events; the main thread keeps a read-only snapshot for panels/clicks/save/exports (~150 touch-points).
