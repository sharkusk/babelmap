--- note 2026-07-16T18:54:18Z ---

Decision (2026-07-16): KEPT as a deliberate step toward the standing goal "only the interpreter on the main thread, all else in the background." Important finding: the "delay" that motivated this was mostly a DEBUG-build artifact — the user confirmed the RELEASE build is a lot faster (the O(map) map draw + routing are far slower unoptimized). On explored-room moves nothing re-routes (SQ-0378 memo hit), so the step overlay never appeared and the felt delay was the unoptimized draw, not map computation. We keep the async worker anyway because off-thread map rendering is required by the target architecture and the ~one-frame lag is inherent to it. Full vision (future) moves graph OWNERSHIP to a persistent worker fed by interpreter events; the main thread keeps a read-only snapshot for panels/clicks/save/exports (~150 touch-points). See memory background-processing-direction.

--- note 2026-07-17T08:03:07Z ---

Root-caused the real gameplay slowdown: apply_turn (session.rs) called cleanup_overlaps EVERY turn in Auto mode — even look/inventory — and cleanup_overlaps runs a full map route (render_overlap_stats->render) at least once per call. On a large map that was ~2.1s/turn in debug (measured turn=2133ms, all in apply), ~100-200ms release, and multi-pass seconds on new-room overlaps. Fix (this session): (1) removed the synchronous cleanup from apply_turn; (2) added cleanup_overlaps_layer_silent (tidy.rs) sharing a run_layer_ops_silent helper with tidy_layer_silent; (3) TidyKind{Full,Cleanup} on TidyJob — finish_command_turn now spawns a background job ONLY on a geometry change: Full relayout when should_bg_tidy fires (config), else Cleanup-only, so overlaps are always cleaned off-thread regardless of the background_tidy setting; (4) abort-and-replace on rapid movement (drop the in-flight handle, spawn fresh for latest state) since the job is per-command; render_job keeps per-frame coalescing. All map jobs pulse. User confirmed 'working great' on a real large map. Remaining main-thread map work: replay/tidy-anim per-frame render_layer + map-dump (new quest), and mark_distorted in observe (sub-ms).
