--- note 2026-08-21T18:29:04Z ---

TWO defects, stacked — the first hid the second, and both are the same mistake twelve lines apart.

1. `protocol/halfblocks/primitive.rs:26` allocated `(size.width * size.height) as usize` (u16 multiply, wraps) while line 33 indexed `x + (size.width as usize) * (y / 2)` (usize). Past 65535 cells the buffer is allocated modulo 65536 and the loop walks past its end. Reproduced standalone at Size 458x144 = 65952 cells: `index out of bounds: the len is 416 but the index is 416` at primitive.rs:33:21 — byte-for-byte the user's report.

2. `protocol/halfblocks.rs:85` derived `let x = i as u16 % self.size.width` with `i` a usize cell index. Past 65535 the narrowing wraps, so cells beyond the ceiling are drawn at aliased coordinates near the origin: the image paints its lower rows over its top rows and never draws its true bottom. This is what the user's screenshot showed (a strip of card-bottoms at row 0, bottom row missing). Falsified: restoring the narrowing makes the first row of a red-over-blue image come out Rgb(0,0,255).

Seven more of the same shape in `cells * font_size` (lib.rs:416/417/473/474, sliced.rs:246/247) do not panic — they silently compute a wrapped pixel dimension. Nine sites total, three files.

NOTE THE PROFILE SPLIT: in debug, overflow-checks fire on the multiply itself (panic at primitive.rs:26, "attempt to multiply with overflow"); in release it wraps silently and dies at the index. Every test we run is a debug build, so this bug has a different shape under the gate than in the shipped binary — which is why no local test could have found it in the form the user hit.

Upstream PR: https://github.com/ratatui/ratatui-image/pull/189 (2 commits, against master).
Patch branch: sharkusk/ratatui-image@lanthorn-11.0.6-u16-fix = the v11.0.6 release commit + both commits, deliberately NOT master (master carries an unrelated change to ioctl/env font-size detection, the very input this geometry derives from). Wired via [patch.crates-io] in the workspace root; Cargo.lock pinned to b7799bb.

User confirmed scopa now renders the full board at near-native resolution under half-blocks at a small font.
