--- note 2026-07-22T01:54:20Z ---

Decode detail: a Z-string is a stream of big-endian 16-bit words, each packing three 5-bit Z-characters, with the high bit of a word marking the final word. The DECODER reads 2-byte words forward from the exact (clicked) byte address until the end-bit word — the start address is a plain byte address and need NOT be even-aligned (dict entry = base + i*entry_length with arbitrary entry_length; object short-name follows a 1-byte length field so is often odd; only PACKED string addresses unpack to a 2/4/8 boundary). Reuse zvm's existing decode_string (text/decode.rs) which already does exactly this. Scope: dictionary word field + object property-table short-name; annotate/preview the decoded string when the memory view is jumped to (or hovering) such an entry.
