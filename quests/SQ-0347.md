Implemented + merged to main (merge e86562ef). In the story-picker info panel's Resources list, Pict/Snd rows are now clickable links; clicking one pops a centered modal (reuses render::dialog draw_dialog chrome — border, title, ✕ close, Close button). An image renders fitted+centered into the content rect; a sound plays once via a lazily-constructed audio::AudioBackend held for the picker loop's lifetime (out-of-VM, mirrors the /play path). Undecodable Pict / no-audio-device degrade to a status line. Dismiss via Esc/Enter/q, the ✕, the Close button, or a click outside; the modal swallows wheel+keys so the list behind it doesn't move. New glue: draw_info_panel records (Rect, ResourceRef) per previewable row (ChunkInfo carries no bytes, so a click re-reads the blorb from disk — story's own path for self_blorb, sidecar path for assoc_blorb). Headless: 1488 lib + 71 bin tests green (added info_panel_records_a_hit_rect_for_a_previewable_pict_row, open_preview_decodes_an_image_resource_from_a_blorb, open_preview_of_a_missing_blorb_yields_a_status_not_a_panic); no new clippy beyond the pre-existing draw_story_picker complex-type warning.
