User addition (2026-07-15): Right arrow at the END of the line, when a suggestion is showing, must ACCEPT the suggestion (fish/zsh autosuggest style) rather than move the cursor. Anywhere else in the line, Right moves the cursor as normal.

So Right is context-dependent and the two behaviours must be designed together, not bolted on:
  - cursor at end + suggestion present -> accept the suggested text
  - otherwise                          -> move cursor right one char

Note the existing suggestion model already distinguishes preview from applied: state.suggestion_active is false after typing (the candidate at suggestion_idx is only a PREVIEW shown in brackets) and true once a Tab press has applied it. Accept-on-Right should apply the previewed candidate the same way Tab does, so the two paths agree.
