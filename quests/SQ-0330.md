CLOSED on partial verification (2026-07-29). User smoked the Emphasized -> italic change in a
live Glulx session and confirmed it.

The LAYOUT hints (Indentation=0, ParaIndentation=1, Justification=2) were NOT smoked
end-to-end, because nothing available exercises them. Scanned every Glulx binary in
`unit_tests/` — including `glulxercise.ulx`, Plotkin's Glk exerciser — for the strings
"indent", "justif" and "stylehint": zero hits across the lot (`windowtest.ulx` mentions
"style" once). No game in the story library or the test corpus calls `glk_stylehint_set`
with those three hints; they are among the least-used in the spec, since authors assume a
monospace terminal cannot honour them.

What DOES cover them: unit tests at both layers from eae5a2e3 — gvm records the hints and
reports them truthfully through `style_measure`/`style_distinguish`, and the app's wrap turns
them into leading padding with each row's runs shifted so selection/copy/search stay
coordinate-consistent. A game that sets no hint gets a default `ParaFmt` and byte-identical
output, which the Z-machine byte-identical test pins.

The gap is the SEAM: a real game setting a hint and the padding appearing on screen. Judged
acceptable — narrow risk, small blast radius, and no fixture exists to close it.

If it ever needs proving, two options were identified, cheapest first:
  1. drive `set_style_hint` on a booted session headlessly and assert the rendered
     transcript's leading spaces — covers the seam, stops short of real Glk dispatch;
  2. build a minimal `.ulx` fixture that sets each hint and prints a paragraph — true
     end-to-end and it would live in `unit_tests/` permanently, but needs an Inform 6
     toolchain.
