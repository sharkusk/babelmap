  Found while doing SQ-0988: re-deriving the terminal's cell size on resize has to go through the deprecated Picker::from_fontsize and then copy the protocol type back, because the fork exposes no set_font_size. That silently drops `capabilities` (text-sizing protocol) — unused by lanthorn today, so it is correct now and quietly wrong the day anything reads it. A one-line `pub fn set_font_size(&mut self, fs: FontSize)` on the fork removes the hazard.
