--- note 2026-07-13T23:52:20Z ---

Captured design direction (from SQ-0161 planning, 2026-07-13 — do NOT implement until the user decides):

Current pain: style.toml → Decl map → apply_color_decls giant match → 84-field ColorScheme → 247 direct field reads in render/. The selector↔field mapping is spelled out 5× (SELECTOR_FIELDS, SELECTOR_GROUPS style.rs:163/228, style_for_selector :267, apply_color_decls :407, write_style_full :1291). Adding one themeable element = 8-9 touchpoints. No inheritance. Explorer verdict: a flat key→style map in disguise — migration-friendly.

Chosen approach (over full Textual CSS-lite, for simplicity): **registry + single-level fallback.** Keep TOML syntax (no new parser, no cascade/specificity engine); schema may change freely — no backwards compatibility required (user decision). One declarative selector-registry table is the ONLY place a selector is declared — each row: name, editor group, kind (style / border+glyphs / placement), default, and an optional parent selector + delta (e.g. dialog:button:active → parent dialog, delta REVERSED). A resolve pass computes the final flat theme map once (base scheme → registry defaults/parents → user decls → per-game overlay); unset selectors inherit their parent at resolve time.

Stages: (4a) registry + schema design spec, user-approved — parent/delta assignments for all 54 selectors, simplified TOML schema, default-theme story, README notes the format break (old style.toml not migrated); (4b) registry + resolver replaces the 5 enumerations; per-game overlay merge (incl. reset/none story), statusbar template, [symbols], transcript rules carried over; (4c) render-site migration to theme.get(sel::X) — 84 signatures/247 reads, temporary facade OK; (4d) style editor / gallery / per-game save driven by the registry; docs + new style.example.

Payoff: adding a themeable element drops to 1 registry row + the render apply site. Verify: registry completeness test (parse/resolve/round-trip/exactly-one-group per selector), editor smoke, per-game override smoke, default theme visually stable across CM/Kerkerkruip/a Z-machine title.
