--- note 2026-08-09T21:01:02Z ---

Found while fixing SQ-0732 (THE BAT's boot banners), by driving every Glulx story in stories/ through boot + ten turns and logging each Subheader heading with the input kind the turn ended at.

cragne.gblorb prints, as its very first page:

    CONTENT WARNING\n\nPlease be warned that this game contains:\n\ncosmic horror, ...\n\nWould you still like to continue? (Please type yes or no.)\n

"CONTENT WARNING" is an own-line Subheader, so it is a heading candidate, and it is still detected as a room after SQ-0732.

WHY SQ-0732's RULE DOES NOT CATCH IT. That fix rejects a candidate only when BOTH halves agree: (a) a blank line detaches the heading from the prose below it, AND (b) the turn ends by asking for a keypress rather than a typed command. cragne satisfies (a) but not (b) — it asks you to TYPE yes or no, so the turn ends at a Glk line-input request exactly as a real room does. The keypress half cannot simply be dropped: Adventure in superbrief prints "Inside Building", a blank line and nothing but its object list, and (a) alone throws that real room away (measured; pinned by a_superbrief_room_with_only_an_object_list_is_still_a_room in crates/app/tests/glulx_banner_rooms.rs).

So a third discriminator is needed, and it is NOT obvious what it should be — cragne's page is textually the same shape as a superbrief room. Candidates worth measuring before choosing: the heading is ALL CAPS; the game has not yet reached its first command prompt (a pre-game gate); no room heading has ever been seen before and the graph is empty (the NameOnly-empty-graph gate that RoomHeading deliberately bypasses). Do not guess — the SQ-0732 method (drive the corpus headlessly, log every heading, then pick a rule that keeps every real detection) is the one that works here.

Low priority: one spurious node on one game's map, dropped as soon as the player answers.

--- note 2026-08-10T04:19:55Z ---

RULED OUT as sharing a cause with SQ-0752/SQ-0731, 2026-08-09, from the SQ-0752 lane. Not touched; still open and still needs its own third discriminator. Why it is a different bug, in two ways. (1) DIRECTION: the four Z-machine titles in SQ-0752/0731 (The Impossible Bottle, The Impossible Stairs, Facility.z8, frankenfingers) all fail by UNDER-detection — a room found and then suppressed — while cragne fails by OVER-detection, a non-room admitted. (2) PATH: those four are the Z-machine NameOnly path and were fixed by relaxing the empty-graph gate in apply_turn to accept CORROBORATION (the status-line name is also printed as its own heading line in the story text). cragne is Glulx/RoomHeading, which that gate never applied to and which this change does not touch. Worse, corroboration is actively USELESS here and would point the wrong way: 'CONTENT WARNING' IS the story-text heading, so it is corroborated by construction — the very evidence that rescues the other four would admit cragne's page. So the shared-cause hypothesis is measured and rejected: the outcome is one general rule for four titles plus this one genuinely separate defect, not a fifth rung. The candidate discriminators listed in the note above (ALL CAPS; no first command prompt reached yet; empty graph) are untouched and still the right place to start, and the SQ-0732 method — drive the Glulx corpus headlessly, log every heading, pick a rule that keeps every real detection — remains the one that works. Note for whoever takes it: the Z-machine side now has a precedent for 'named twice, in two independent channels' as the test for a real room; on Glulx both channels are the same buffer, which is exactly why cragne is harder.
