--- note 2026-08-12T06:56:20Z ---

FOUND 2026-08-11 by the SQ-0789 lane, which was told to bind its new gestures through the single `slash::COMMANDS` registry — the project's standing rule that keys bind to command strings rather than hardcoded match arms — and reported that it could not, with the reason, rather than quietly hardcoding and saying nothing.

**The story browser is a self-contained pre-game loop that never constructs `AppState`.** It uses neither `keymap` nor `slash`, verified by grep: **zero references to either in `picker_ui.rs`**. The registry's contexts are `Global` / `Map` / `Anim`, all of which are in-game. Routing browser keys through it would need a new context, new `Action` variants, and an `AppState` the picker does not have.

So the rule *"all commands live in one `slash::COMMANDS` registry"* ([[command-registry]]) is true of the running app and **silently false of the browser**, which is a surface with a growing key set: Enter, double-click, Tab/Shift-Tab into IFDB search, and now Shift-Enter / `o` / double right-click for launch options.

WHAT THE LANE DID INSTEAD, and why it is not merely a workaround: both the keyboard and mouse paths call one function, `open_launch_options(entry, cfg, data_base)`, which is the **only** place the dialog is constructed. That delivers the anti-drift property the rule exists to protect — the two gestures cannot seed the dialog differently — without the registry. Worth knowing that the goal was met even though the mechanism was not available.

WHAT THIS QUEST IS: extend the registry to cover the browser, so its keys are data like everything else. Likely shape — a `Browser` context, the `Action` variants its keys need, and enough state threading that `picker_ui` can dispatch through the same path. Whoever takes it should decide whether the browser gets a cut-down dispatch or whether `AppState` construction moves earlier; the second is larger and touches startup.

WHY IT IS WORTH DOING, beyond tidiness: keys that are data can be **rebound**, listed, and documented automatically. The browser's are none of those things today, so every new gesture is a hardcoded arm plus a hand-written footer hint that can drift from it — which is exactly the kind of divergence the registry was introduced to end.

NOT URGENT. Nothing is broken; this is structural debt with a clear boundary. Do not attempt it alongside lanes working in the picker or render paths.
