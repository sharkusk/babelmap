  Surfaced by SQ-0227's final review: SavesExport writes a Save State (resume-PC) as <ifid>.qzl into the saves dir, and SQ-0227 widened the host saves manager (list_qzl) to list .qzl files — so loading that exported file would treat its resume PC as an @save descriptor and silently misexecute (same-IFID => no SaveMismatch guard).
