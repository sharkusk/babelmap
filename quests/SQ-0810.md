--- note 2026-08-12T17:22:41Z ---

RULED OUT so far, each measured rather than reasoned (2026-08-12):

1. **The GarGlk sentinel** — works. `kk.i7x`'s `DetectGargoyleConfigFile` needs `res != 0 && gg_arguments-->0 == $F400A1`; our backend answers `style_User2` = 0xF400A1 on the buffer row, and a controlled same-file boot shows ini=true → `Event` + empty transcript, ini=false → `Char` + the screen-reader prompt. NOT the cause.

2. **The cover-image title** — works. `display the text menu` branches on `if glulx text-buffer graphics is supported` (our `gestalt_DrawImage(wintype_TextBuffer=3)`, `gvm/src/exec.rs:5577`, gated on `graphics_enabled`). With graphics off the transcript carries "Kerkerkruip -- by Victor Gijsbers"; with graphics on it is empty, so the figure path is taken. NOT the cause.

3. **Timers** — `gestalt_Timer` answers 1 (`exec.rs:5575`) and the app arms Glk timer deadlines (`loop_tick.rs:375`). An animation track needs these and they are present. NOT obviously the cause.

4. **Graphics windows draw** — the boot dump shows `Graphics id=5 80x23 canvas=640x368 opaque=235520`, i.e. a real populated graphics window. NOT the cause.

5. **Hyperlink input** — initially suspected, then refuted by the user: the menu IS reachable and the game IS startable. (`main.rs:3080` does swallow Enter while a Glulx game waits on `Event`, which is correct, not a block.)

WHERE IT ACTUALLY LIVES, and why this stalled: the animated menu is implemented in **"Kerkerkruip Glimmr Additions" by Erik Temple**, which is NOT in the local source copy. `kk.i7x` only carries the fallback, explicitly marked `Section - Fading out the theme music B (for use without Kerkerkruip Glimmr Additions by Erik Temple)` with the note "This is used only for the text menu--the graphics menu uses an animation track." So the selecting condition is in an extension we do not have.

NEXT STEP: fetch Kerkerkruip's full source (it is open source) plus the Glimmr Additions extension, and find what gates the animation track — Glimmr is a Glk graphics-drawing framework, so the likely candidates are a gestalt or Glk capability it probes that we answer differently, NOT the garglk.ini path which is now proven working.

METHOD NOTE, worth heeding: four wrong inferences were made on this before the user supplied the discriminator ("the basic intro spells 'attack', the special one says 'sprout 4'"). Each was a plausible mechanism measured carefully and none was the reported symptom, because the symptom itself had not been pinned down first. Get the observable difference before choosing what to measure.

--- note 2026-08-12T18:18:35Z ---

RESOLVED BY SQ-0811, confirmed by the user 2026-08-12: "i got the new animation first try with the new seed!"

THE CAUSE WAS THE FIXED RNG SEED, not any Glk capability. The intro animation IS selected at random; both VM cores seeded their PRNG from a fixed constant at construction (gvm `DEFAULT_SEED = 0x2BADC0DE`, zvm the same shape), so every launch dealt the identical sequence and Kerkerkruip picked the same animation — "attack", starting at blorb image 47 — forever. With the seed drawn from entropy the user reached the "sprout 4" sequence (image 79) on the first try.

WORTH RECORDING ABOUT THE INVESTIGATION, because the near-miss is instructive. The RNG was hypothesised here and then WRONGLY SET ASIDE on a bad measurement: two boots were compared by hashing the graphics canvas under two different DEFAULT_SEED values, the hashes matched, and that was read as "the intro is not RNG-selected". The test could not have detected it — it hashes the canvas at BOOT, which is the first frame, before any animation track has run. The limitation was noticed and stated at the time but the hypothesis was dropped anyway rather than the test being fixed.

The four mechanisms ruled out in the earlier note (the GarGlk sentinel, the cover-image gestalt, timers, graphics-window drawing) were all correctly ruled out and none was the cause — they were simply never where the answer lived. The Glimmr Additions extension was never needed after all.

LESSON, and the same one SQ-0795 recorded: get the observable difference pinned before choosing what to measure. Four careful measurements were made here before the user supplied the discriminator ("the basic intro spells 'attack', the special one says 'sprout 4'"), and a fifth was made against a surface that could not show the effect.
