--- note 2026-08-09T18:22:59Z ---

MEASURED 2026-08-09 while closing SQ-0697's second half. Shogun's title screen in RASTER mode shows the frozen banner and the menu correctly and NO prose at all — "You may choose to:" never appears. Rendered the composite to PNG to confirm.

CAUSE, measured: `v6_layout::story_clear_native` shrinks the story window's box edge-by-edge until no edge row/column carries an opaque chrome pixel. Shogun's story box is (46,336) 548x64 — four rows — and window 2 (the menu) sits INSIDE it at (234,336) 169x48 with an erase fill, which lands on the paint ground. The shrink therefore eats the top three rows:

    story_clear_native = Some((46, 384, 548, 16))     -- one row of four

and `build_main_text(state, 68, 1)` on a one-row box returns `lines: []`, `viewport_rows: 0` (`RasterMetrics { total_rows: 10, viewport_rows: 0, max_scroll: 10, first_visible_row: 10 }`). So the box collapses to one row and that row then renders nothing. `build_main_text(state, 68, 4)` — the box the game actually declared — returns the right thing: ["Release 322 / Pix 322 / Serial number 890706", "IBM Interpreter version 6.65", "You may choose to:"].

TWO DEFECTS, either of which alone would hide the prose:
1. `story_clear_native` treats a chrome window painted OVER the story as if it bordered it. Insetting past bordering frame art is the function's purpose and is right (Zork Zero's frame, Arthur's plate); a menu window that overlaps the story box is the game deliberately drawing on top of window 0, and both coexist on a real interpreter — the prompt at x=47, the menu at x=235, same rows.
2. A one-row story box yields ZERO visible transcript rows. Even after (1), a genuinely tiny box should show its one line rather than nothing.

NOT a regression from the SQ-0697 freeze, and not from SQ-0715/0717/0721: the raster arm is untouched by all of them, and before the freeze the same shrink applied to the same box. Shogun's title has never shown prose in raster.

SCOPE NOTE: deliberately left undone by the SQ-0697 agent. The reported bug, the approved design and the corpus were all about where the RESUMED transcript lands, which is now correct in hybrid, frameless and the cell fallback. Fixing (1) means changing what `story_clear_native` counts as an obstruction, which is load-bearing for Zork Zero's hints/InvisiClues screens, scopa and Journey — a guess there is exactly the kind of render-geometry change the standing rule says to check with the user first.
