## REFRAMED — the quest's premise is wrong in an instructive way

User: "in nerd fonts, ⊗ can be found at f05c, and ⊙ at f192. not sure why they don't exist in the unicode space. they are rendering in our terminal so not sure where they are coming from."

Measured directly from the font cmaps:

  FiraCodeNerdFontMono-Regular       U+2297 no   U+2299 no   U+F05C YES  U+F192 YES
  JetBrainsMonoNerdFontMono-Regular  U+2297 YES  U+2299 YES  U+F05C YES  U+F192 YES

U+F05C and U+F192 are **Private Use Area** codepoints — where Nerd Fonts patch their icon set, IN ADDITION to whatever the base face already carried. JetBrains Mono's base face happens to include those two mathematical symbols; Fira Code's does not.

**So they render in a terminal for one of two reasons**: the face has the real codepoint (JetBrains Mono), or the terminal's font-FALLBACK chain finds another system font that does (Fira Code). Either way the user sees a glyph.

**A terminal has a fallback chain. Our gallery rasteriser does not.** `bitfont`/`fontdue` draws with the one named face, so a missing glyph is blank. That is where the blank badge lives — in gallery shots, and only since SQ-0963 moved them to Fira Code. It is NOT the user-facing defect this quest was filed as. The SQ-0963 lane already added a per-glyph capability fallback to the bitmap master for exactly this, and reported that no shot in the current manifest reaches these two.

## The real defect underneath, which is a different one

`crates/app/src/render/map.rs:1811-1815` hardcodes all five portal glyphs as consts, with the comment "Named so a font that renders a variant better is a one-line swap" — a one-line swap IN SOURCE. That contradicts the standing rule that every UI element must be styleable via a `style.toml` selector and never hard-coded.

The machinery already exists: the theme registry carries `glyph` on a selector and supports a `glyphs = { … }` sub-map (`crates/app/src/theme/registry.rs:48-58`, the same mechanism map `box_style` presets use).

**Make the portal glyphs themeable and the font question answers itself per user**: a Fira Code user sets U+F05C/U+F192, a JetBrains Mono user keeps the Unicode pair, someone on a bare console picks ASCII. Hardcoding EITHER choice is wrong — PUA codepoints have no meaning without a Nerd Font and would be tofu for anyone else, while the Unicode pair depends on a fallback chain the gallery does not have.

Also worth doing while there: `PORTAL_UP`/`PORTAL_DOWN` (↑ ↓) and `PORTAL_UNKNOWN` (?) are hardcoded in the same block and should move together.
