  Surfaced debugging a Glulx in-game-graphics crash: an abort (stack overflow / OOM / SIGSEGV / SIGABRT) bypasses the panic hook, so restore_terminal() never runs and the abort's stderr message is written to the alternate screen and discarded on exit — the app vanishes with no message and no crash.log. Principle from the user: never silent-quit on error, only on clean exit.
