  Surfaced debugging a Glulx in-game-graphics crash: an abort (stack overflow / OOM / SIGSEGV / SIGABRT) bypasses the panic hook, so restore_terminal() never runs and the abort's stderr message is written to the alternate screen and discarded on exit — the app vanishes with no message and no crash.log. Principle from the user: never silent-quit on error, only on clean exit.

--- note 2026-07-03T18:54:22Z ---

Partially addressed (commit 45b8c21, on main): the CounterfeitMonkey "silent crash" turned out to be a recoverable gvm VM fault (unimplemented float opcode) converted to a silent Quit, NOT a signal abort. The app now distinguishes a fault-quit from a clean glk_exit, survives it (stays interactive: transcript/map/scrollback/deliberate-quit), shows the fault, and writes it durably to ~/.babelmap/crash.log. The panic hook also writes panics+backtrace to crash.log. STILL OPEN: true signal aborts (SIGSEGV/SIGABRT/stack overflow/OOM) still bypass the panic hook and terminal restore, so their message is eaten by the alternate screen. Remaining work: install SIGSEGV/SIGABRT handlers that restore the terminal + report before dying.
