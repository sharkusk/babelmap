SCOPE DECIDED (user, 2026-07-29). Queue position 3 of 3: SQ-0522 -> SQ-0525 -> SQ-0391.
Independent of the other two — it adds new state rather than touching the router.

DECISION: "Untried only", and it must be a TOGGLE, OFF BY DEFAULT.
Draw `?` on compass directions never typed in that room, and nothing else. No `x` for
blocked moves, no change to the existing arrows — a pure "where haven't I been" prompt.
The original title's ?/arrow/x three-state scheme is SUPERSEDED by this.

Consequence of dropping `x`: a wall you have already bumped into keeps showing `?` forever,
since a direction that was typed but did not move you is indistinguishable from an untried
one under this scheme. The user accepted that. (If it grates in play, the state below is
enough to add `x` later without a re-record — record the outcome even though nothing draws
it yet.)

STATE NEEDED — none of this exists today. `mapper::graph::Room` has no notion of attempted
moves. Add a persisted per-room set of directions typed there (`#[serde(default)]`, as
`loc_method` did for SQ-0527, so old map files still load). Populate it where a direction
command is observed: `Mapper::observe_command` already runs `parse_direction(command)`, and
`observe` sees whether the location actually changed — a typed direction with
`location == prev_id` is the "tried, went nowhere" case. Record the direction regardless of
outcome; `?` simply means "not in the set".

Note `observe` currently leaves `arrived_via` untouched when `location == prev_id`; do not
disturb that (SQ-0552).

UI REQUIREMENTS.
- Toggle modelled on `toggle-room-numbers`: a command in the single `slash::COMMANDS`
  registry (verb-noun), default OFF. Remember the registry count is asserted in a test.
- The `?` glyph must be themeable via a style.toml selector — a ColorScheme field, a
  selector in style.rs, and the render applying it. Never hard-code the style.
- Placement: the room box is BOX_W=11 x BOX_H=5 with per-side border slots
  (`box_edge_anchor` / `slot_offset`). Eight `?`s on a fresh room is a lot of ink — check
  what it looks like on a real map before settling, and confirm a `?` never displaces a
  real connector's anchor slot.
- Which directions get a `?` is the open sub-question: all 8 compass, or the 4 cardinals
  only. Decide from a screenshot at the user's ~138x51 pane, not in the abstract.
