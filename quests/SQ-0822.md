Root-caused to TWO independent causes; neither is SQ-0740's window-0 gate, which stands.

1. DEF_BACK is 12 (dark grey $444), not the 11 ($777) that amiga/yzip.h gives. The leaked header is a development snapshot. Every Amiga release floppy in stories/ carries its own 68000 interpreter, and in all four set_back()'s `if (id == 1) id = DEF_BACK` compiles to `cmpi.w #1,d7 / bne.s / moveq #12,d7`, while set_color()'s `return ((DEF_BACK<<8)|DEF_FORE)` assembles to `move.w #$0C09,d0`. $0B09 occurs in none of them. Real captures agree: Arthur's church screen is #444444 under #FFFFFF with the status bar reversed to #444444 ON #FFFFFF (pens 0/1 swapped, so the page is the text background register, not artwork), and lemonamiga's Journey r30 gallery tallies 173,994 px of #444444 under 25,878 of #FFFFFF.

   CONSEQUENCE THE USER MUST JUDGE: Journey's page moves too, from Rgb(115,115,115) to Rgb(66,66,66). The "light grey" in SQ-0740's reasoning was the right observation one shade too pale — what it established is that Journey is not BLACK, which a dark-grey page also satisfies.

   The same floppies also correct colortable[5] (standard colour 5, yellow) from the source's $0EE0 to the shipped $0FD0.

2. Arthur's bracketed notices are the GAME's prose (Default/Default runs). They were dimmed by babelmap's own built-in "a whole line in [brackets] came from the interpreter" rule in ColorScheme::resolve_story_style, whose payload is transcript_system — a muted colour picked to recede against the THEME's page. Against the Amiga's dark grey it reads as grey on grey. The rule now stands down while the machine owns the ink; user transcript rules and the room-heading accent are unaffected.

   Incidental finding: Arthur r54 DOES call set_colour — a dozen `set_colour(0, 0, window=3)` calls, each after `get_wind_prop(win=3, prop=11) -> 0`. Both channels are the "leave alone" sentinel, so it moves nothing anywhere. SQ-0740 recorded "Arthur sets no colours" because twelve blank turns never get past "Please press Y or N>".

New suite crates/app/tests/suites/v6_amiga_shipped_interpreter.rs reads the palette and the default pair back off the release floppies on every run, so a future reader reaching for yzip.h is told by a failing test.
